TESTING
Extract ZIP; open index.html for quick preview, or host the whole folder on
HTTPS (required for PWA installation). For all 30 stories, open the grown-up
corner, answer the math question, and enable Preview all worlds this session.
Normal startup exposes the seven free animals. Preview resets on reload.
For future recordings run python extras/rebuild_assets.py; separately review
and update recording status sets in index.html. Regenerate the cache version
also after any code update. No external fonts or tracking SDKs included.
